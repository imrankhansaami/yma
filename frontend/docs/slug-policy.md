# URL Slug Policy

## Rules

- Slugs must be lowercase.
- Slugs must use `a-z`, `0-9`, and hyphen only.
- Underscores are not allowed.
- Multiple separators are collapsed to a single hyphen.
- Leading/trailing hyphens are trimmed.
- Product slugs are generated by backend from product name.

## Canonical Behavior

- Dynamic pages use stored canonical slugs.
- Old slugs resolve through aliases and redirect permanently to canonical URL.
- Non-canonical name/id URL fallbacks are not used for product detail links.

## Checklist

- Include `slug` in API payloads for linked entities.
- Do not generate detail URLs from title or ID fallback.
- Keep static route segments kebab-case.
- Run `npm run routes:audit` before release.
